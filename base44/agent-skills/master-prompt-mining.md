description: Detect recurring workflows and turn them into reusable Master Prompts with locked rules, variables, versioning, and user approval.
---

Use this skill when analyzing prompt history, saved projects, imported conversations, or existing Master Prompts for reusable patterns.

1. Group by underlying job, not only exact wording.
2. Distinguish Frequent, Recurring, One-Off, Duplicate, and Update Existing patterns.
3. Extract the stable instructions as Locked Rules.
4. Extract the changing details as Variables.
5. Identify the purpose, recommended prompt name, platform, and intended output.
6. Compare against existing Master Prompts before proposing a new one.
7. Prefer updating or merging over creating duplicates.
8. Never modify an approved Master Prompt without explicit user approval.
9. Before any update, show what is changing and preserve the previous version.
10. If the evidence is weak, mark confidence as limited instead of inventing a pattern.
