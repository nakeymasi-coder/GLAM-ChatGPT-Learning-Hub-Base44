Use this skill when the user asks to learn how a ChatGPT feature, mode, tool, workflow, or prompting technique works.

1. Start from the user's demonstrated level. Do not repeat beginner material they already understand.
2. Explain what the feature is, why it matters, when to use it, and when not to use it.
3. Give one practical Glam Hustle Hub example when relevant.
4. For click-by-click tasks, say exactly what to click, what to look for, and what should happen next.
5. Separate stable concepts from account-specific or rollout-specific behavior.
6. If the answer depends on current ChatGPT product behavior, verify it with the current-information tool before teaching it as fact.
7. End with one clear next action rather than a long list of homework.
